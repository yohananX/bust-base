{% comment %} Generic search autocomplete for list pages. Loads all entries once (localStorage cache, revalidated via conditional GET / HTTP 304 when the API supports it), then filters entirely in the browser. Arrow keys navigate, Enter selects, Esc closes. The input keeps name="q" so the enclosing filter form still works on submit. Usage: {% include 'components/search_autocomplete.html' with cache_key='students' api_path='/school-admin/api/students/' item_url='/school-admin/students/{id}/' placeholder='Search…' %} - cache_key : localStorage namespace for this entity (per school) - api_path : JSON endpoint returning [{id, name, subtitle}] - item_url : detail/action URL template containing {id}. Omit for "fill the input then submit the form" behaviour. - placeholder: input placeholder text {% endcomment %}
